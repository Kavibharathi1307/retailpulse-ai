# data/

This directory holds local retail sales and inventory datasets for RetailPulse
AI.

- Raw data files (CSV/JSON/Parquet) will be placed here in later milestones.
- Data here is treated as input data, **not** application source code.
- For now the directory intentionally contains no data files.

Data parsing and deterministic analytics will be kept in the backend
(`src/`), separate from any future Gemini-based reasoning.
